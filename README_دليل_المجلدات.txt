================================================================================
          دليل المجلدات الرئيسية - أداة تشغيل ديسكورد الآمنة في تركيا
================================================================================

تم تنظيم وتوزيع المشروع إلى 4 مجلدات رئيسية مستقلة ومنفصلة تماماً:

1. [1_Discord_GUI] - النسخة الرسومية الفاخرة:
   - واجهة مستخدم رسومية حديثة باللونين الأسود والبنفسجي.
   - خط عربي رسمي واضح 100% (بدون علامات استفهام).
   - بطاقات حالة مباشرة، وتصغير بجانب الساعة (System Tray)، وتشغيل تلقائي مع ويندوز.
   - ملف التشغيل: Discord_Safe_GUI.exe

2. [2_DosiFix_Cleaner] - أداة الإصلاح الشامل واستعادة النظام:
   - أداة طوارئ مستقلة لإصلاح أي جهاز واجه مشاكل في كروت الشبكة أو خروج حسابات كروم
     أو إزالة أي بروكسي معلق وإعادة كل شيء للوضع التلقائي بنقرة واحدة كمسؤول.
   - ملف التشغيل: DosiFix.exe

3. [3_Discord_CMD] - النسخة الكلاسيكية السريعة (CMD):
   - تعمل عبر موجه الأوامر الكلاسيكي الخفيف بنظام المصافحة الموقوتة والعزل التام (Direct 100%).
   - ملف التشغيل: Discord_Safe.exe أو turkey_dnsredir.cmd

4. [4_Discord_Gaming_Launcher] - مشغل الألعاب المزدوج والإشعارات الذكية:
   - يدمج الخيارين (3 و 4): إطلاق ديسكورد مع لعبتك المفضلة (Valorant أو Call of Duty) بنقرة واحدة.
   - إشعارات ويندوز المنبثقة الناعمة (Toast Notifications) التي تؤكد جاهزية اللعب.
   - معزز أولوية المعالج للألعاب (High CPU Priority Boost) لتثبيت الفريمات ومنع أي لاغ.
   - ملف التشغيل: Discord_Gaming_Launcher.exe
